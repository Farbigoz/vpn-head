# Резервное копирование и восстановление

## Что копируем и куда

Копии хранятся на дирижёре (`backup_dir`, по умолчанию
`/srv/vpn-head/backups`) и — по желанию — синхронизируются на локальный
ПК в каталог `backups/` репозитория (не коммитится, см. `.gitignore`).

С ноды `<нода>` (в `backups/nodes/<нода>/`):

| Что | Зачем |
|---|---|
| БД 3x-ui ноды (`/etc/x-ui/x-ui.db`) | UUID клиентов, инбаунды, настройки |
| Конфиг Xray (`/usr/local/x-ui/bin/config.json` или экспорт) | Транспорты, REALITY short ID |
| REALITY private key | Перенос без перенастройки клиентов |
| Учётные данные Hysteria2 | Те же пароли после переезда |
| AWG server/peer keys и `.conf` | Те же ключи после переезда |
| Сертификаты (если есть) | Быстрый подъём без перевыпуска |

С дирижёра (в `backups/conductor/`):

| Что | Зачем |
|---|---|
| БД master 3x-ui + PostgreSQL dump | Учётные записи, подписки, ноды |
| Конфигурация Semaphore и Uptime Kuma | Задачи, мониторинг |
| acme.sh (`~/.acme.sh/`) | Выпущенные сертификаты |
| Инвентарь и vault.yml (копия) | Полное восстановление управления |

## Принципы

- Бэкап ноды делается **перед** любыми изменениями на ней и по расписанию.
- Шифрование копий при выносе за пределы дирижёра — обязательно
  (копии содержат все ключи).
- Периодически проверяйте восстановление на тестовом VPS: невосстановимый
  бэкап не бэкап.

## Восстановление ноды на новом VPS

Короткий путь — это ровно процедура замены VPS:
`docs/node-replacement.md` (этапы 01 → 02 с восстановлением из
`backups/nodes/<нода>/` → 03 → 04).

## Восстановление дирижёра

1. Поднять чистый VPS/машину, накатить базовые пакеты.
2. Восстановить `backups/conductor/` в исходные пути.
3. Поднять 3x-ui master, Semaphore, Uptime Kuma, acme.sh (плейбук
   подготовки дирижёра — на этапе реализации).
4. Проверить, что дирижёр видит ноды по их `node_fqdn` (UFW на нодах
   открывает панель только для `conductor_ip` — при смене IP дирижёра
   обновите инвентарь и повторите `01-prepare-node` для всех нод).
5. Помните: пока дирижёр лежал, ноды и клиенты работали без него —
   восстановление не критично по времени.
